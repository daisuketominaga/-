# PC健康診断セット（Windows 11 / 10 用）

パソコンの「どこが重いのか」「何を消せば空くのか」「壊れかけていないか」を調べて、
日本語のレポートにまとめる道具です。**調べるだけで、勝手に何かを消したり変えたりはしません。**

| ファイル | 役割 |
| --- | --- |
| `run-health-check.bat` | **これをダブルクリックすれば診断が始まります**（調べるだけ） |
| `pc-health-check.ps1` | 診断の本体（PowerShell スクリプト） |
| `run-cleanup.bat` | 片付け用。1つずつ「実行しますか？」と聞いてから掃除します |
| `pc-cleanup.ps1` | 片付けの本体 |

---

## 1. 使い方（3ステップ）

1. このフォルダー（`tools/pc-health-check`）を、パソコンのデスクトップなど分かりやすい場所に置きます。
   GitHub から持ってくる場合は、リポジトリの「Code → Download ZIP」で全部落として、このフォルダーだけ取り出せばOKです。
2. `run-health-check.bat` を**ダブルクリック**します。
   - 黒い画面が開いて「このアプリがデバイスに変更を加えることを許可しますか？」と聞かれたら **「はい」** を押してください。
     （管理者権限があると、ディスクの温度・摩耗度など、より多くの項目を調べられます。「いいえ」でも診断は続きます。何も変更はしません）
   - 「Windows によって PC が保護されました」という青い画面が出たら、「詳細情報」→「実行」を押してください。
     （インターネットから持ってきたファイルに Windows が出す標準の確認です）
3. 2〜5分ほど待つと、デスクトップに **`PC健康診断_日付_時刻`** というフォルダーができ、
   `PC健康診断レポート.html` が自動で開きます。

できるファイル:

| ファイル | 内容 |
| --- | --- |
| `PC健康診断レポート.html` | 見やすいレポート（ブラウザで開く） |
| `PC健康診断レポート.txt` | 同じ内容のテキスト版 |
| `summary.json` | Claude などに読ませるための要約データ |
| `battery-report.html` | Windows 標準のバッテリー詳細レポート（ノートPCのみ） |

---

## 2. レポートの見方

一番上の **「総合判定」** と **「総合所見 — やるべきこと一覧」** だけ見れば十分です。

| ラベル | 意味 |
| --- | --- |
| **高（要対応）** | 放っておくとデータが消える・動かなくなる恐れ。早めに対応 |
| **中（改善推奨）** | 直すと体感で速くなる・安定する |
| **低（できれば）** | 片付け系。やらなくても困らないが、やると気持ちいい |

それぞれの項目に「やること」として、設定画面のどこを押せばいいかを書いてあります。

その下に、調べた内容が13項目（基本情報、ディスク、容量を使っている場所、大きいファイル、メモリ、
スタートアップ、Windows Update、セキュリティ、バッテリー、エラー記録、アプリ一覧、電源設定）並びます。

---

## 3. 片付けを実行する（任意）

診断で「安全に消せるもの」が多かった場合は、`run-cleanup.bat` をダブルクリックしてください。
次の8つの手順を、**1つずつ「実行しますか？ (y/N)」と聞いてから**行います。`y` と打って Enter で実行、それ以外なら飛ばします。

1. ごみ箱を空にする
2. ユーザーの一時ファイル（7日以上前のもの）を削除
3. Windows の一時ファイル（7日以上前のもの）を削除 ※管理者権限
4. Windows Update のダウンロード済みファイルを削除 ※管理者権限
5. Windows 標準の「ディスク クリーンアップ」を開く（画面でチェックを付けて消す）
6. 更新プログラムの残りかすを整理（DISM）※管理者権限・数分〜十数分
7. ドライブの最適化（SSD はトリム、HDD はデフラグ）※管理者権限
8. システムファイルの整合性チェック（sfc /scannow）※管理者権限・10〜20分

**写真・書類・メール・アプリなど、あなたが作ったものや入れたものには一切触れません。**
ブラウザのキャッシュも触りません（各ブラウザの「閲覧履歴データの削除」から消してください）。

## 4. Claude に実行と結果報告を任せる方法

クラウド上の Claude（この仕組みを作ったセッション）からは、あなたのパソコン本体を直接操作できません。
**パソコン上で動く Claude** に頼むと、実行から結果のまとめまで任せられます。

- **Claude デスクトップアプリの「Claude Code」でこのリポジトリを開き**、次のように頼む:

  > `tools/pc-health-check/pc-health-check.ps1` を `-NoElevate -NoOpen` 付きで実行して、
  > できた `summary.json` と `PC健康診断レポート.txt` を読んで、やるべきことを日本語で分かりやすくまとめて

- Claude デスクトップアプリに「提案されたタスク」のカードが届いている場合は、そのカードから
  「このパソコンで実行」を選ぶだけで同じことが始まります。

## 6. 注意事項

- このスクリプトは Windows 標準の PowerShell 5.1 以降で動きます。追加のインストールは不要です。
- `run-health-check.bat` は「調べるだけ」です。`run-cleanup.bat` だけが削除を行い、しかも毎回確認します。
- OneDrive の「ファイル オンデマンド」で雲マークになっているファイルも、サイズは正しく数えます（ダウンロードはしません）。
- 他社製のウイルス対策ソフトを使っている場合、「Microsoft Defender が無効」と出るのは正常です。
- 診断結果の「やること」はあくまで一般的な目安です。業務で使う大事なパソコンで大きな変更（ディスク交換・Windows の初期化など）を行う前には、必ずバックアップを取ってください。
