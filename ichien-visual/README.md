# イチエン物件ビジュアル工房

測量図から「敷地図・建築可能範囲・間取り図・立面図」を作り、現地写真の明るさを一括で揃える、イチエン不動産の社内ツールです。

## できること

| 画面 | 内容 | 費用 |
|---|---|---|
| 写真一括補正 | 現地写真を20〜30枚まとめて入れ、明るさ・色味を「明るい／自然／暖かい／すっきり」で統一してZIP保存 | 無料（ブラウザ内で処理） |
| 敷地図 | 測量図（画像/PDF）をAIが読み取り、境界点・辺長・道路・面積を図面化。求積表の座標から辺長を計算して図面の表記と並べて確認。民法234条の50cm離れ線 | 読み取り時のみClaude API |
| 建築可能範囲 | 敷地の一辺を底辺に選び、910mmグリッド（455mm刻み）を引いて、離れ線の内側に入る建物の枠を決める。建ぺい率の確認。この枠が間取り図の外形になる | 無料 |
| 間取り図 | 部屋と建具を一覧からドラッグして455mm刻みで配置（家具は描かない）。階段は直階段・回り階段（1820×1820）・かね折れで向きつき。建具は片開き・引き戸・引違い・折れ戸・玄関・親子・腰窓・掃き出し窓・小窓・開口。日本語の指示で編集。階ごとの床面積と延床の表つきでPNG出力 | 指示編集時のみClaude API |
| 立面図 | 4面の立面図。間取り図に置いた窓・玄関ドアが自動で反映。基礎高・階ごとの天井高・片流れの勾配（寸）・高い側を指定。高さ基準線と材料の凡例つき | 無料 |
| 印刷・PDF | 敷地図・配置図・間取り図・立面図を1つにまとめ、ブラウザの印刷から「PDFに保存」で書き出す（A4横） | 無料 |

物件は複数保存でき、画面上部で切り替えられます（ブラウザ内に保存）。「ファイルに保存」でJSONにも残せます。

## セットアップ

```bash
cd ichien-visual
npm install
cp .env.local.example .env.local   # ANTHROPIC_API_KEY を設定
npm run dev
```

Vercel にデプロイする場合は、Root Directory を `ichien-visual` にし、環境変数 `ANTHROPIC_API_KEY` を設定してください。

現在は既存の Vercel プロジェクト（旧 ryourikensaku）をこのアプリに付け替えて運用しています（プロジェクト数を増やさないため）。
本番URL: https://ichien-visual.vercel.app （旧URL https://ryourikensaku.vercel.app も同じ内容）

## 建物の形・法規チェックの前提（2026-09 更新）

- 建物は「外接する矩形 ＋ 角の切り欠き（最大4か所）」で表します。L字・コの字はこれで作れます。建築面積・斜線・天空率・日影はすべて切り欠き後の形で計算します。
- 屋根は 片流れ／切妻／寄棟／陸屋根。母屋下がり（面ごと）と軒の出も入力でき、立面図の輪郭は屋根の3次元形状を奥行方向に走査して描きます。
- 天空率は「直方体を閉じた式で積分した値」との検算をスクリプト（`scripts/skytest.ts`）に入れています。この検算で、レイの向きの扱いに誤りがあり天空率が 0.5〜3 ポイント高く出ていた不具合を見つけて直しました（2026-09-26）。
- 日影規制は冬至の真太陽時 8〜16 時を 5 分刻みで計算し、5m/10m 線の範囲ごとに最大日影時間を出します（令135条の12 の道路幅 1/2 の扱いを含む）。対象・測定面・時間は自治体の条例値を都市計画図から入力してください。
- 横浜市の高度地区（最高限第1〜7種）は、横浜市建築基準法取扱基準集（令和8年4月版）58〜59頁の告示（平成23年横浜市告示第506号）の原文から転記し、「原文確認済み」にしています。北側の道路等は幅の1/2だけ外側を境界とみなす緩和と、敷地が北側隣地より1m以上低い場合の高低差緩和も計算に入れています。高度地区（法58条）は天空率（法56条7項）ではかわせません。
- 天空率は道路斜線に加えて、隣地斜線（令135条の7）と北側斜線（令135条の8）にも対応しました（斜線を超えたときだけ境界線ごとに計算）。適合建築物の後退緩和は未対応です。
- 他の自治体の高度地区の数値は検索要約からの転記で未確認のものが多いため、「資料から式を読み取る」で取扱基準のPDF・都市計画図の凡例を貼ると Claude が式を読み取り、その値を使えます（読み取り結果も原文との照合が必要）。
- 教材3 は架空の3階建て（教材2の敷地）で、天空率・日影・L字・寄棟の動作確認用です。実在の設計図ではありません。

## 法令の扱い

- 境界からの離れは民法234条1項（50cm）を基本表示にしています。
- 防火地域・準防火地域で外壁が耐火構造の建物は、建築基準法65条により境界に接して建てられるため、切り替えで離れ線を非表示にできます（最判平成元年9月19日）。
- 民法236条により、異なる慣習がある地域ではそれに従います。

図面は参考図です。面積は概算で、建築には別途設計・建築確認が必要です。実際の取引前には宅建士・建築士等の専門家による確認を推奨します。
