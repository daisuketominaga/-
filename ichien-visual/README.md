# イチエン物件ビジュアル工房

測量図から「敷地図・間取り図・立面図・外観イメージ」を作り、現地写真の明るさを一括で揃える、イチエン不動産の社内ツールです。

## できること

| 画面 | 内容 | 費用 |
|---|---|---|
| 写真一括補正 | 現地写真を20〜30枚まとめて入れ、明るさ・色味を「明るい／自然／暖かい／すっきり」で統一してZIP保存 | 無料（ブラウザ内で処理） |
| 敷地図 | 測量図（画像/PDF）をAIが読み取り、境界点・辺長・道路・面積を図面化。民法234条の50cm離れ線、建物配置、建ぺい率・容積率の確認 | 読み取り時のみClaude API |
| 間取り図 | 建物外形の中に部屋を配置。日本語の指示（例「ガレージを50cm広く」）で編集。階ごとの床面積と延床の表つきでPNG出力 | 指示編集時のみClaude API |
| 立面図 | 4面の立面図。基礎高・階ごとの天井高・片流れの勾配（寸）・高い側を指定。高さ基準線と材料の凡例つき | 無料 |
| 外観イメージ | 3D模型風の外観（回転・太陽の時刻）。写真のようなパースを作るための指示文を自動生成 | 無料 |

作った内容はブラウザに自動保存されます。「保存(JSON)」でファイルにも残せます。

## セットアップ

```bash
cd ichien-visual
npm install
cp .env.local.example .env.local   # ANTHROPIC_API_KEY を設定
npm run dev
```

Vercel にデプロイする場合は、Root Directory を `ichien-visual` にし、環境変数 `ANTHROPIC_API_KEY` を設定してください。

## 法令の扱い

- 境界からの離れは民法234条1項（50cm）を基本表示にしています。
- 防火地域・準防火地域で外壁が耐火構造の建物は、建築基準法65条により境界に接して建てられるため、切り替えで離れ線を非表示にできます（最判平成元年9月19日）。
- 民法236条により、異なる慣習がある地域ではそれに従います。

図面は参考図です。面積は概算で、建築には別途設計・建築確認が必要です。実際の取引前には宅建士・建築士等の専門家による確認を推奨します。
